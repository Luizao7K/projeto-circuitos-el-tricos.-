Projeto de Monitoramento de Temperatura e Umidade com IoT (ESP32)

Este projeto acadêmico foca na criação de um sistema de monitoramento ambiental utilizando um sensor DHT22 para coletar dados de temperatura e umidade. A arquitetura do sistema é composta por um microcontrolador ESP32, que funciona como o gateway IoT, lendo os dados do sensor, controlando atuadores e enviando as informações para a nuvem através de um servidor web integrado.

Contribuição para os ODS (Objetivos de Desenvolvimento Sustentável)

Este projeto está alinhado com vários Objetivos de Desenvolvimento Sustentável da ONU, contribuindo para avanços tecnológicos que promovem a sustentabilidade e o bem-estar social. As principais ODS impactadas são:

  • ODS 3: Saúde e Bem-Estar

    O monitoramento da temperatura e umidade pode ser crucial para manter ambientes saudáveis, prevenindo a proliferação de mofo e bactérias em locais como escolas, hospitais e residências.

  • ODS 11: Cidades e Comunidades Sustentáveis

    Ao fornecer dados ambientais de baixo custo, a tecnologia do projeto pode auxiliar na gestão de espaços urbanos, tornando as cidades mais inteligentes e resilientes.

  • ODS 13: Ação Contra a Mudança Global do Clima

    A coleta de dados de temperatura e umidade em diferentes localidades pode apoiar pesquisas e ações de monitoramento climático, contribuindo para a conscientização sobre as mudanças ambientais.

Código-Fonte para o ESP32

Este é o código principal que roda no ESP32. Ele é responsável por se conectar à rede Wi-Fi, criar um servidor web, ler os dados do sensor DHT22 e controlar os atuadores (representados por LEDs) com base em limiares de temperatura e umidade. Ele também fornece os dados para o aplicativo via uma URL específica (/dados).


#include <WiFi.h>
#include <WebServer.h> 
#include <Adafruit_Sensor.h>
#include "DHT.h"

const char* ssid = "luis";
const char* password = "12345678";

WebServer server(80); 

#define DHTPIN 4
#define DHTTYPE DHT22

#define HUMIDIFIER_PIN 18
#define AC_PIN 19

DHT dht(DHTPIN, DHTTYPE);

const float HUM_MIN = 55.0;
const float HUM_MAX = 65.0;
const float TEMP_MIN = 18.0;
const float TEMP_MAX = 28.0;

float currentHumidity = 0.0;
float currentTemperature = 0.0;

void readAndControl() {
  float h = dht.readHumidity();   
  float t = dht.readTemperature(); 

  if (isnan(h) || isnan(t)) {
    Serial.println("Falha ao ler do sensor DHT!");
    return;
  }
  
  currentHumidity = h;
  currentTemperature = t;

  if (currentHumidity < HUM_MIN) {
    digitalWrite(HUMIDIFIER_PIN, HIGH);
  } else if (currentHumidity >= HUM_MAX) {
    digitalWrite(HUMIDIFIER_PIN, LOW);
  }

  if (currentTemperature > TEMP_MAX) {
    digitalWrite(AC_PIN, HIGH);
  } else if (currentTemperature < TEMP_MIN) {
    digitalWrite(AC_PIN, LOW);
  }
}

void handleDataRequest() { 
  readAndControl(); 
  String response = String(currentTemperature, 2) + "," + String(currentHumidity, 2);
  server.send(200, "text/plain", response);
}

void handleRoot() { 
  String html = "<h1>Monitor de Clima ESP32 (Wi-Fi)</h1>";
  html += "<p>Temperatura: " + String(currentTemperature, 2) + " °C</p>";
  html += "<p>Humidade: " + String(currentHumidity, 2) + " %</p>";
  html += (String)"<p>Estado Umidificador: " + (digitalRead(HUMIDIFIER_PIN) == HIGH ? "LIGADO" : "DESLIGADO") + "</p>";
  html += (String)"<p>Estado AC: " + (digitalRead(AC_PIN) == HIGH ? "LIGADO" : "DESLIGADO") + "</p>";
  html += "<p>Para o App Inventor, use a URL: <b>/dados</b></p>";
  server.send(200, "text/html", html);
}

void setup() {
  Serial.begin(115200);
  dht.begin();
  
  pinMode(HUMIDIFIER_PIN, OUTPUT);
  pinMode(AC_PIN, OUTPUT);
  
  digitalWrite(HUMIDIFIER_PIN, LOW);
  digitalWrite(AC_PIN, LOW);

  WiFi.begin(ssid, password);
  while (WiFi.status() != WL_CONNECTED) {
    delay(500);
    Serial.print(".");
  }

  Serial.println("\nConectado!");
  Serial.print("IP do Servidor: ");
  Serial.println(WiFi.localIP());

  server.on("/", handleRoot);          
  server.on("/dados", handleDataRequest); 
  server.begin();
  Serial.println("Servidor HTTP iniciado.");
}

void loop() {
  server.handleClient();
  delay(100); 
}
